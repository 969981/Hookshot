# A hand-drawn PS5 controller face

The pictures in this folder replace the ones the build draws from the Kenney
font for the `ps5` prompt face (see `nx2/prompt_faces/README.md` for how the
overrides work).

The controller picture (`Controller_Pro.png`), the tinted copy the build makes
of it, and the five guide-line textures (`ControllerGuide_Pro_00..04.png`) were
drawn by hand for this project. They come from the author's Ocarina of Time
DualSense Controller UI mod and are contributed to Hookshot as original work by
YG, offered free of charge for inclusion, modification, and redistribution
under Hookshot's project license (GPL-3.0), to the extent of the author's
rights. No game art or game-extracted data is used: the textures these files
replace are made at build time from the game's own RomFS plus Kenney glyphs,
and only the shapes drawn here are substituted.

Nothing else about the face changes: the button icons stay the ones the build
makes from the Kenney PlayStation font, and the Switch, Xbox, PlayStation 4 and
Steam Deck faces are untouched.
